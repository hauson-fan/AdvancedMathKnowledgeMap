# 微积分知识图谱

一个**单文件、离线可跑**的微积分定义与定理知识库：把一元微积分的定义、定理、推论整理成可检索、可跳转、可看依赖关系的交互式知识图谱。

打开 [`index.html`](index.html) 即用，无需安装、无需联网。

## 特性

- **单文件交付**：`index.html` 内联了 KaTeX、Cytoscape.js、dagre 及其全部字体，以及知识库数据本身。双击即可打开，不发起任何网络请求。
- **公式用 LaTeX 排版**：全部 1177 个数学表达式由 KaTeX 渲染，不使用图片或纯文本近似。
- **依赖图谱**：121 个条目、282 条依赖边，方向恒为「前置 → 后继」。点击节点即可看到它的直接前置与后继。
- **Lean 风格证明链**：定理的证明被拆成 567 个显式步骤，每一步标注它用了哪些前提（本条目第几步、或哪些其他定理），可点击跳转。
- **检索**：按编号、中文名、英文名、别名搜索，支持类型与章节筛选。
- **可消费的数据**：[`data.json`](data.json) 是结构化知识库，可被其他程序直接读取。

## 快速开始

直接双击 `index.html`，或拖入浏览器。

也可以起一个本地静态服务（若浏览器对 `file://` 有额外限制）：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000/
```

支持的浏览器：近几年的 Chrome / Edge / Firefox / Safari（需要 ES2017 与 woff2 字体）。

## 知识库结构

`data.json` 的 schema 版本为 2.2。

### 顶层

| 字段 | 说明 |
|---|---|
| `meta` | 标题、覆盖范围、写作约定、`schema_version` |
| `items` | 121 条条目 |
| `graph.direction` | 恒为「前置 → 后继」 |
| `graph.edge_kinds` | 四类边的语义说明 |
| `graph.edges` | 282 条依赖边：`{source, target, kind, label}` |

### `items[]`

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 唯一主键，规则 `(def\|thm\|cor\|lem\|prop)-<章>.<序>` |
| `type` | string | `definition` / `theorem` / `corollary` / `proposition` / `lemma` |
| `number` | string | 显示编号，如「定理 2.11」「推论 1」 |
| `name` | string | 中文名 |
| `name_en` | string | 英文名 |
| `aliases` | string[] | 别名、常用缩写、中英变体（搜索只匹配这三个名称字段） |
| `chapter` / `chapter_title` | number / string | 章号、章名 |
| `section` / `section_title` | string | 小节号、小节标题 |
| `origin` | string | `source`（有对应条文依据）/ `supplement`（标准补充条目，页面显示「补充」徽章） |
| `statement` | string | **唯一权威表述，纯 LaTeX**（不含 `$`），中文用 `\text{}` 包裹，多行用 `\\` 分行 |
| `symbols[]` | `{latex, mean}` | 符号说明。`latex` 是纯 LaTeX；`mean` 是混排文本，算式用 `$...$` 包裹 |
| `deps[]` | `{ref, kind, note}` | **前置**条目（由 `graph.edges` 派生） |
| `used_by` | string[] | **后继**条目 id（同上，派生字段） |
| `proof` | object | 见下 |

### `$` 的语义约定

两类字段的约定**相反**，这是最容易踩坑的地方：

| 字段 | 约定 | 示例 |
|---|---|---|
| `statement`、`symbols[].latex`、`proof.steps[].claim` | **纯 LaTeX，不含任何 `$`**，整串交给 KaTeX | `A_n=\dfrac{x_1+\cdots+x_n}{n}` |
| `symbols[].mean`、`proof.steps[].note` | **混排文本**，`$...$` 是行内公式定界符 | `数列的第 $n$ 项（通项）` |

### `\\` 的语义约定

LaTeX 中 `\\` 是**换行命令**，误用会静默破坏版式：

| 字段 | `\\` | 说明 |
|---|---|---|
| `statement` | 合法 | 长陈述分行书写 |
| `symbols[].latex`、`claim` | 应为 0 | 当前用法确实为 0 |
| `symbols[].mean`、`proof.steps[].note` | **不允许** | 行内短句不需要换行 |

### `items[].proof`

| 字段 | 说明 |
|---|---|
| `in_book` | bool。`true` 表示该证明是随条目一并收录的现成证明；`false` 表示由本库独立补写，页面在方法行标注「此证明由本库补全」 |
| `method` | 证明方法概述 |
| `steps[]` | Lean 风格证明步骤链 |

`steps[]` 每步：

| 字段 | 说明 |
|---|---|
| `id` | 本条目内的步骤号（字符串，从 `"1"` 起） |
| `claim` | 该步的断言，纯 LaTeX |
| `by` | 该步显式用到的依据。`"#3"` 表示本条目第 3 步；裸 id（如 `"thm-2.13"`）表示其他条目 |
| `note` | 依据说明（混排文本） |

### 消费示例

```js
const data = await (await fetch("data.json")).json();

// 某条目的全部前置
const item = data.items.find(i => i.id === "thm-4.3");
console.log(item.name, item.deps.map(d => d.ref));

// 图上的全部出边
console.log(data.graph.edges.filter(e => e.source === "thm-4.3"));
```

```python
import json

with open("data.json", encoding="utf-8") as f:
    data = json.load(f)

item = next(i for i in data["items"] if i["id"] == "thm-4.3")
print(item["number"], item["name"])
for st in item["proof"]["steps"]:
    print(st["id"], st["claim"][:60], st["by"])
```

## 编号规则

编号统一采用 **「类型 + 章.序」** 体例，`序` 在本章内连续。多数条目自带现成编号，直接沿用；少数结论在表述中**没有独立编号**（多以「推论」「由此得到」「同理可证」行文给出），由本库在同一章内统一编排序位，以保证全库编号唯一、同章连续、`id` 与 `number` 一一对应。

具体哪些条目属于后一种情况，见 [KNOWN_LIMITATIONS.md](KNOWN_LIMITATIONS.md#四编号规则)。

## 已知限制

覆盖范围、证明来源、编号细节、依赖边语义与校验边界，见 **[KNOWN_LIMITATIONS.md](KNOWN_LIMITATIONS.md)**。

需要先知道的三点：

1. 这是**定义与定理的骨架**，不是完整教程 —— 例题、习题与公式表未系统收录。
2. 第 5、6 章（积分、微分方程）**尚未收录**。
3. 交互行为按代码逻辑与人工检查确认，**没有**做真实浏览器端的自动化 E2E 测试。
